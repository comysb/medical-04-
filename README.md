🦴 골밀도 상관관계 분석 및 대시보드 프로젝트
이 프로젝트는 국민건강영양조사(KNHANES)와 같은 공공 보건 데이터를 활용하여, 사용자의 일반적인 신체 정보(연령, 성별, 영양 섭취 등)와 골밀도(Bone Mineral Density, BMD) 사이의 상관관계를 분석하고 이를 시각화하는 대시보드를 제공합니다.

📝 프로젝트 개요
골밀도는 골다공증 및 골절 위험을 판단하는 중요한 지표입니다. 본 프로젝트는 전문적인 의료 장비 없이도 일상적으로 수집 가능한 데이터를 통해 골밀도 저하의 위험 요인을 탐색하고, 데이터 기반의 통찰을 제공하는 것을 목적으로 합니다.

🚀 주요 기능
데이터 통합 및 전처리: 여러 도메인의 데이터(.sav, .sas7bdat)를 통합하고 결측치 처리 및 변수명 표준화 수행.

상관관계 분석: Pearson 및 Spearman 상관계수를 활용하여 골밀도와 주요 변수 간의 통계적 유의성 검정.

인터랙티브 대시보드: Streamlit을 사용하여 사용자가 직접 필터를 조정하며 분석 결과를 확인할 수 있는 웹 대시보드 구현.

데이터 시각화: Seaborn 및 Matplotlib을 활용한 분포도, 선 그래프, 막대 그래프 시각화.

🛠 기술 스택
Language: Python 3.10+

Library: Pandas, Pyreadstat, Scikit-learn, Seaborn, Matplotlib

Framework: Streamlit
📊 분석 결과 예시
성별 및 연령: 연령 증가에 따른 골밀도 감소 추이 분석.

영양소 섭취: 특정 영양소(칼슘, 단백질 등)와 골밀도 수치 간의 양의 상관관계 확인.

생활 습관: 신체 활동량 및 흡연 유무가 골밀도에 미치는 영향 분석.
